# Frontend client

`frontend-client` is the public QTS marketing website. It contains landing
pages, solution pages, resources, SEO metadata and the consultation form.

- Package: `@qts/web`
- Local development: `npm run dev:web`
- Production build: `npm run build:web`
- Docker port: `3000`

The consultation form calls the public lead consultation API. Authentication
and business application navigation belong to the portal and identity folders.
